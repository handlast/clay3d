# 发布文案 · 《这只蝴蝶躲了200年？》

**标题**：这只蝴蝶躲了200年？

**正文**：
中南美洲雨林里最常见的蝴蝶之一 Colobura，从 1758 年林奈命名起，被当成同一种蝴蝶两百多年，直到 2001 年才分出第 2 种。佛罗里达自然史博物馆团队在 2026 年的 Zootaxa 上描述了第 3 种 Colobura cryptica（意思是“藏起来的”）：三种翅膀几乎一模一样，要靠毛虫花纹（泪滴斑、圆环、没有斑）、DNA 和翅膀反射的紫外光才分得开，起因是委内瑞拉一群身上没有斑的毛虫。三种住在同一片森林、同时出现，核 DNA 里却没发现杂交，它们会不会靠人眼看不见的紫外光认出同伴，科学家还在研究。

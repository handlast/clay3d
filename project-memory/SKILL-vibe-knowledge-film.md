# Skill：Vibe知识大赏 · 代码生成短片工作流（要点）

方法：程序化动画——Python + Pillow 逐帧绘制，numpy/采样合成 BGM，ffmpeg 合成 mp4。无实拍、无 AI 生图。

## 代码结构
- cues.py：画面与音乐共用时间轴。PRE/POST 字幕列表（key, 文本, 额外秒），need() 自动算停留；BIG2 紧跟上一句结尾，不加静音拍；`python3 cues.py` 打印检查。
- music.py：只读 cues；org() 在 BIG2 重设小节原点；loudnorm −15 LUFS。采样见 sf/samp.py（piano/gm/drum；GM 电平：马林巴×0.12、Melodic Tom×0.15、木鱼×0.25、Taiko×0.2、Koto×0.2）。
- film.py：1.5× 超采样后 LANCZOS 缩小；每段一个场景函数；`film.py test t1 t2…` 出测试帧；render.sh 切段渲染（每命令 2 段）再 mux。
- 底图用 RGB + ImageDraw(img,"RGBA") 才能半透明；文字淡入用 L 蒙版。

## 画面规则
- 深色或明亮分段背景，每句讲解一个专属场景（静音也看得懂）；不能一个镜头到底；切场 ≤0.5 s 叠化，硬切白闪只给两个大重音。
- 带夸张表情的扁平卡通角色；无黑色描边（五官线条可深色）；只用一个强调色标新信息。
- 0 帧主体就动，0.5 s 内出字，≤7 s 给承诺句；核心命题 = BIG2 ≤20 s；每 2–3 s 一个画面节拍；先例子后术语；比较左右并排；结尾回扣开头。
- 卡点：大重音只 0 s 和 BIG2，其余用木鱼/拨弦/pop/tom 轻音效；抖动大重音 8px、卡点 1.5px；冲击变焦 4%/1.5%。
- 加一张“一句话学会”知识卡（≥3 s）。

## 数据复盘结论
- 最好：《捕蝇草会数数》（完播 10.25%）——动画表情+卡点+停顿+光效+粒子+跳动叠加最抓人。
- 失败：开头慢、横屏、太长、老梗钩子、片名卡拖延。

## 交付
- 成片、无旁白版、压缩版 <40 MB、srt、script.md（事实出处与口径）、publish.md；不做封面。

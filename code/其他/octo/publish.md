标题：章鱼越狱只要三步？科学家拆解了它的钻孔套路｜Vibe知识大赏

正文：
研究者用3只普通章鱼和4只玛雅章鱼做实验：先量两眼间距，用它估算章鱼最硬的部位——包住大脑的软骨有多宽，再把它们放进亚克力盒，孔比这个宽度略大或略小。
孔比两眼间距宽时，普通章鱼三步出盒：先伸出一两条腕，再穿过几条，最后用外面的腕撑住盒子，把头和剩下的腕一把拽出，前后只要几秒。孔更窄就加一步：所有腕先塞出去，最后再挤头和外套膜。
玛雅章鱼遇到窄孔通常理都不理，研究者推测可能和它们住在沙地岩石区、不太需要钻窄缝有关。团队希望这套动作能启发会变形钻孔的软体机器人。

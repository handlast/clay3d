# props
- `basics.py`：背景墙、地板
- `jungle_plants.py`：树、藤、灌木、蕨
- `office_props.py`：办公桌、咖啡杯
- `charts.py`：秒表、柱子、台阶
- `links.py`：关系连线（直线/拱形）
- `anemone.py`：`anemone()` 海葵（bleach 0..1 健康→白化，spread 逐根扫白，droop 下垂，face 小脸）、`thermometer()` 体温计
- `camera_rig.py`：`camcorder()` 水下摄像机 + 三脚架 + 录制灯
- `hive_props.py`：熊蜂巢道具——`brood()` 育雏团（蜡座 + 睡脸幼虫 + 卵，幼虫可按 born 时间逐只弹入）、`honey_pot()` 蜜罐、`lab_box()` 实验室透明小巢（可落盖上锁）、`flower()` 野花、`thermo_cam()` 热成像相机（动物打工人 No.04）

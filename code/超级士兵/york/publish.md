# 发布文案 · 超级士兵 No.02

**标题**
Vibe知识大赏｜一个不想打仗的农村神枪手，怎么让132名敌军投降？

**正文**
1918年10月8日，法国阿尔贡森林，美军下士阿尔文·约克所在的小队被山上的机枪压得抬不起头。
据他回忆，他先趴下，敌人一探头就打一枪，一边打一边喊话劝降，最后德军军官举手投降。
他曾登记为“良心拒服兵役者”，最终却和7个战友押回了132名俘虏（嘉奖词：4名军官 + 128名士兵）。
